### 5 klaim paling berisiko bila dikutip di skripsi

1. **#75 teknologi:80, sandbox cap-drop ALL dan no-new-privileges untuk scanner dan aplikasi.** Risiko: container Semgrep, Trivy, dan audit dependency dijalankan dengan `docker run --rm` tanpa kedua flag itu (src/lib/scanner/run.ts:64-99); penguji yang membaca kode scanner bisa membantah klaim isolasi. Kalimat aman: "Container aplikasi hasil generate dijalankan dengan cap-drop ALL dan no-new-privileges; container pemindai dijalankan sekali pakai (--rm)."
2. **#44 README:203, provider dev aktif bila GitHub OAuth belum dikonfigurasi.** Risiko: anak kalimat "atau" menyiratkan akun dev bisa aktif di produksi; kode justru menolak melayani (HTTP 503). Kalimat aman: "Provider login dev hanya terdaftar saat NODE_ENV bukan production; di production tanpa GitHub OAuth aplikasi menolak melayani (HTTP 503)."
3. **#78b teknologi:130-131, CRUD proyek.** Risiko: /api/projects hanya punya POST dan /api/projects/[id] hanya PATCH; tidak ada handler GET atau DELETE proyek. Kalimat aman: "API proyek menyediakan pembuatan (POST) dan pembaruan (PATCH); data proyek dibaca oleh halaman server."
4. **#67 teknologi:64, default provider Google Gemini.** Risiko: fallback kode di src/lib/ai/resolve-model.ts:64-65 adalah `openai` dan `gpt-4o-mini`. Kalimat aman: "Nilai default dari .env.example adalah Gemini `gemini-flash-latest`; bila env tidak diisi, kode jatuh ke OpenAI `gpt-4o-mini`."
5. **#89 teknologi:266, 30+ sub-step.** Risiko: src/lib/stages.ts berisi 26 sub-step. Kalimat aman: "Lima tahap Secure SDLC dengan 26 sub-step berurutan."

Kelima klaim di atas sudah ditangani pada 2026-11-24 lewat perbaikan kode (#75) atau penyelarasan dokumen (#44, #78b, #67, #89).

## 6. Batas audit

**1. Tidak diperiksa karena butuh runtime atau kredensial.**

- Push ke GitHub (#13, #91b): diuji 2026-11-24 lewat route aplikasi dengan PAT fine-grained dan repo nyata (docs/audit/verifikasi-runtime.md). Butir PR revisi (#81b) baru bisa diuji setelah token diberi izin Pull requests.
- Login OAuth GitHub: tidak dijalankan; keberadaan provider Terealisasi (#5, #56), alur login butuh kredensial.
- Panggilan model AI (#87b): Tidak dapat diverifikasi; butuh API key dan jaringan.
- Run container, SSE log, dan security scan Docker (#24, #25, #27): diuji 2026-11-24 di Docker Desktop Windows (docs/audit/verifikasi-runtime.md); host Linux tidak diuji.
- Render PDF (#19, #91b): Tidak dapat diverifikasi; export butuh kelima tahap selesai dan hasil visual tidak diperiksa.
- Instalasi PWA offline: tidak dicoba; manifest dan service worker Terealisasi (#37, #54).
- Migrasi dan seed pada database nyata: tidak dijalankan; skrip dan perintah container Terealisasi (#12, #39).

**2. Bagian dokumen yang dilewati atau hanya dicuplik.**

- README L24-61, L63-92, L178-197, L199-212: dicuplik untuk env, perintah lokal, skrip verifikasi, dan catatan produksi.
- teknologi L11-20: dicuplik untuk angka 42 task. L94-107: dilewati karena narasi arsitektur. L260-276: dicuplik; L276 (unit test) tidak diberi baris tersendiri.
- DESIGN-BLUEPRINT L8-103: dicuplik untuk font, palet, tipografi, radius, dan shadow; tabel font weight dan spacing tidak diberi baris.
- DESIGN-BLUEPRINT L490-539, L540-598, L599-623, L624-652: dicuplik; L560-570 (stage navigation), L586-595 (step result popup), dan L642-649 (hover states) tidak diberi baris.
- Wireframe ASCII dinilai hanya untuk label dan susunan yang juga disebut di baris spesifikasi atau oleh baris matriks yang ada; label ilustrasi lain (mis. nama proyek contoh di dashboard) tidak dihitung sebagai klaim.

**3. Batas metode.** Tidak ada `npm run build`, `npm run verify`, `npm test`, `npm install`, `npx prisma`, atau pemanggilan API. Bukti adalah bacaan berkas dan perintah `git grep`, `git status`, `git log`, `Get-ChildItem`, `Test-Path`, dan `Select-String`, ditambah dua skrip baca-saja di folder artefak: `hitung-a11y.ps1` (#126a-#126d) dan `hitung-audit.ps1` (#48, #91a, #129). Hitungan ikon, tombol, dan dialog di hitung-a11y.ps1 berbasis regex per tag JSX, bukan parser TSX: ikon yang dirender lewat variabel (`<Icon`, `<feature.icon`) tidak terhitung, dan tag yang memuat `>` di dalam ekspresi bisa terpotong. Angka itu hanya menghitung atribut eksplisit. Untuk ikon (#126a) ukuran itu tidak tepat, karena lucide-react 1.31.0 memasang aria-hidden="true" sendiri saat render (Icon.mjs:36); #126a dinilai dari perilaku pustaka itu. Aturan aria-labelledby dan aria-valuenow pada komponen Radix dinilai dari kode pemanggil; atribut ARIA hasil render Radix tidak diamati di browser. Nilai tema Tailwind (#95, #97, #116, #121) dibaca dari node_modules/tailwindcss/theme.css versi 4.3.3 yang terpasang, bukan dari berkas yang dilacak git. Perintah PowerShell 5.1 membuang tanda kutip ganda di dalam argumen untuk program native, sehingga semua pola grep di dokumen ini ditulis tanpa tanda kutip ganda di dalam pola. Semua status Belum (hanya #135) memakai dua perintah, literal dan konsep, dan keduanya menghasilkan 0 baris. Pencarian penanda kerja belum selesai `git grep -n -i -E "TODO|FIXME|not implemented" -- src` menghasilkan 4 baris, keempatnya false positive: `ListTodo` di src/components/studio/studio-composer.tsx:3 dan :50 adalah nama ikon lucide, sedangkan "todo" di src/lib/markdown.test.ts:17 dan :22 adalah string uji. Status Terealisasi berarti kode ada dan cocok dengan klaim, bukan berarti fitur sudah diuji berjalan.
